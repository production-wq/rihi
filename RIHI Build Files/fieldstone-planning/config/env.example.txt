# -----------------------------------------------------------------------------
# PHASE CONTROL
# -----------------------------------------------------------------------------

# Controls how many city pages get built. THE MOST IMPORTANT VARIABLE HERE.
#
#   0  Service hubs, sub-services, state hubs, static pages, tools. No cities.
#   1  + all 39 Rhode Island municipalities
#   2  + top 50 Massachusetts cities by population
#   3  + all 169 Connecticut municipalities
#   4  + Massachusetts ranked 51 to 150
#   5  + remaining Massachusetts, completing all 559
#
# Do not advance until the current phase clears every gate in CLAUDE.md
# section 5. Roughly 3 to 4 weeks per phase, minimum.
#
# Unset or unparseable values fall back to 0. That default is deliberate: a
# missing variable must never publish four thousand pages by accident.
